## Coursework

### Homework 01 — Convolutional Filters, MLPs, and Generative Models

This assignment explores three topics:

**Question 1: Convolutional Filters**
- Implementing 2D convolution with configurable stride and padding.
- Validating results against PyTorch.
- Exploring edge detection, blurring, and sharpening filters.

**Question 2: Multilayer Perceptron (MLP)**
- Training neural networks on CIFAR-10.
- Comparing batch normalization and dropout.
- Investigating overfitting and regularization.

**Question 3: From a Discriminative CNN to a Generative Model**
- Extracting embeddings from a convolutional neural network.
- Fitting class-conditional Gaussian distributions.
- Exploring Bayesian classification and anomaly detection.

## Running the Notebooks

1. Clone or download this repository.
2. Set up a Python environment and install the required dependencies.
3. Open the notebooks in Jupyter Notebook, JupyterLab, or Google Colab.
4. Follow the instructions and explanations in each notebook.

See `requirements.txt` for the project's Python dependencies.

**Note:** PyTorch installation may need to be adjusted for your operating system and hardware.
